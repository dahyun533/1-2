# 1-2(mission2) 오류를 재현하고, 본 대로 물어서 고치기

코디세이 AI 네이티브 입학연수과정 미션2 제출물.

- **미션:** 오류를 직접 재현해 한 문장으로 좁히고, 본 그대로 AI에게 물어서 고침.
- **한 것:** 일부 영화 카드가 안 옮겨지는 오류를 발견. '해리포터'와 '해리 포터'를 비교해 원인을 '제목의 띄어쓰기'로 좁힘.
- **결과:** 카드 이름표가 띄어쓰기 앞까지만 읽히는 문제를 확인하고 AI에게 요청하여  고침. 띄어쓰기 있는 제목도 정상으로 옮겨짐.
